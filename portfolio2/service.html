制作の流れ

ご相談から納品まで。スピードより「迷わない進行」を大事にします。

基本フロー

  1. ご相談：目的・イメージ・期限の共有（ふわっとでOK）
  2. ヒアリング：必要要素の整理（ページ/掲載情報/素材など）
  3. ご提案：構成案・方向性・概算（必要ならラフ）
  4. 制作：デザイン → 実装（確認しながら）
  5. 納品：データ/公開方法の案内、軽い使い方サポート

※規模によって前後します。急ぎの案件も相談可。

あると助かるもの

  • 参考URL（好きな雰囲気が1〜3個）
  • 掲載したい文章・ロゴ・写真（なくてもOK）
  • ターゲット（誰に見てほしいか）
  • ゴール（予約/問い合わせ/閲覧/購入など）

素材が無い場合は、代替案（仮素材/構成先行）で進められます。

対応範囲

できること/できないことを明確にして、ミスマッチを減らします。

対応できること

  • 静的サイト（HTML/CSS/JS）
  • レスポンシブ・軽いアニメーション
  • GitHub Pages などでの公開サポート
  • Googleフォーム連携・簡易導線の設計
  • 既存ページの軽微な改修（導線/文言/見た目）

要相談 / 対応外

  • 大規模なシステム開発（会員/決済/複雑なDB）
  • サーバー保守・常時監視
  • EC決済の本格構築（外部サービス提案は可）
  • ロゴ制作（簡易バナー等は相談可）

迷ったら「これっていける？」で投げてOKです。
