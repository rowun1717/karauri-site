夜灯り古書店

HTML / CSS / JavaScript

「夜にだけ開く古書店」という世界観をWeb体験として再構築した架空サイト。
ページ全体を“夜”として設計し、スクロールに応じて闇が下へと伸びていく構造を採用している。
背景には多層グラデーションとCanvasによる粒子アニメーションを重ね、静かな空気感と奥行きを演出。
また、JavaScriptで現在時刻を取得し、昼は「準備中」、夜になると開店する仕組みを実装している。

こだわり

  • 「世界観をUIそのものに落とし込む設計」
  • スクロール量と連動する“夜が深まる構造”
  • Canvasによる紙埃の浮遊表現
  • 時刻判定による開店・閉店演出
  • フッターを「夜の底」として扱うレイアウト設計

苦戦

  • CSSのみでの“伸びる夜”構造の実現
  • Canvasアニメーションの負荷調整
  • 時刻取得と表示切替ロジック
  • 世界観を壊さず可読性を保つバランス調整
